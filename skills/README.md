# Claude Code Skills

English | [简体中文](README.zh-CN.md)

Companion [Claude Code](https://claude.com/claude-code) skills for
Zotero Obsidian Linker. They build on the frontmatter that the linker writes
into each note (`zotero_pdf_key`, `zotero_item_key`, …).

## read-paper

A deep paper-reading workflow. Given a paper name, a note file, or a PDF path,
Claude:

1. locates the literature note in your vault and resolves the local PDF from
   its `zotero_pdf_key` frontmatter (written by this plugin);
2. reads the PDF in chunks;
3. writes a structured analysis back into the note's `## Notes` section —
   an eight-part skeleton (TL;DR, problem, contributions, method, experiments,
   critical review, limitations) plus a "why this design, why not the obvious
   alternative" deep-dive on the paper's key design decisions;
4. can crop the method/architecture figure out of the PDF and embed it into
   the note, following your vault's attachment rules;
5. supports a second mode (`/read-paper consolidate`) that distills a
   follow-up Q&A discussion back into the same note.

Safety guarantees: generated content lives inside
`<!-- ai-read-paper:start/end -->` markers; re-running replaces only that
block; handwritten note content is never overwritten.

### Requirements

- An agent supporting the open [Agent Skills](https://agentskills.io) format —
  developed and tested with [Claude Code](https://claude.com/claude-code);
  also loadable in OpenAI Codex CLI and other compatible agents (see notes
  below)
- Zotero with locally stored PDF attachments (default `~/Zotero/storage`)
- Obsidian notes generated by Zotero Obsidian Linker
- [poppler](https://poppler.freedesktop.org/) (`pdfinfo`, `pdftotext`,
  `pdftocairo`) — `brew install poppler` / `apt install poppler-utils`
- Python 3 + [Pillow](https://python-pillow.org/) (only needed for figure
  extraction)

### Install

**Claude Code:**

```bash
cp -r skills/read-paper ~/.claude/skills/
```

**OpenAI Codex CLI** (or other Agent Skills-compatible agents — see the
[Codex skills docs](https://developers.openai.com/codex/skills)):

```bash
cp -r skills/read-paper ~/.codex/skills/
```

Then open the installed `SKILL.md` and fill in the
**配置 (Configuration)** section at the top — note directory, vault root,
research field, etc. Everything machine-specific lives in that one section.

Portability notes for non-Claude agents: the `allowed-tools` frontmatter
field is a Claude Code extension and is safely ignored elsewhere; where the
instructions use Claude Code's built-in `Read` tool for paged PDF reading and
image inspection, other agents fall back to the poppler toolchain (already a
dependency) — the skill includes the fallback commands.

Start a new conversation and try:

```text
/read-paper <paper name>           # full deep read
/read-paper <paper name> quick     # skeleton only
/read-paper consolidate            # distill follow-up discussion into the note
/read-paper fig <paper name>       # crop & embed a figure on demand
```

### Language

The skill instructions and the note template are written in Chinese and
produce Chinese notes with technical terms kept in English (the author's
note-taking convention). If you take notes in another language, edit the
template and writing rules in `SKILL.md` Step 6 — the workflow itself is
language-independent.

### Layout

```text
read-paper/
├── SKILL.md                       # main workflow + configuration section
└── references/                    # loaded on demand
    ├── figure-extraction.md       # figure cropping / naming / embedding
    ├── consolidate.md             # discussion-consolidation mode
    └── example-analysis.md        # calibration samples for analysis depth
```
